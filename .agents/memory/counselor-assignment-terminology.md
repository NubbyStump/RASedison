---
name: Counselor assignment terminology
description: Distinguishes group reassignment from Program Manager access.
---

When the user asks to change counselor “roles,” they mean changing counselors’ group assignments among the program groups. They do not want roster controls that promote counselors to Program Manager.

**Why:** The word “role” can refer to either the app’s privileged Program Manager access or the counselor’s assigned group; the user explicitly rejected promotion as an option.

**How to apply:** Keep Program Manager access separate from counselor group assignments. Let a Program Manager reassign other counselors among groups (including unassigned/view-only), without changing their counselor role.
